# Sidharth R. — Portfolio

Personal portfolio of **Sidharth R.**, Lead Software Engineer at Persistent Systems with 6+ years of experience in Generative AI, Data Engineering, and Cloud Computing. Ex-IBM.

🔗 **Live:** [sidharthrai.com](https://sidharthrai.com)

---

## Tech Stack

- **Framework:** Next.js 15 (Static Export)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion (`motion/react`)
- **Icons:** Lucide React
- **Fonts:** Inter · JetBrains Mono (via `@fontsource`)

---

## Sections

- **Hero** — Intro, social links, floating icons
- **About** — Background, expertise, certifications
- **Services** — Core offerings across AI, data & full-stack
- **Portfolio** — Research papers, patents & enterprise projects (auto-scrolling carousel)
- **Skills** — Proficiency bars across 6 technical domains
- **Experience** — Work history at Persistent Systems, IBM, AXL EV, Tecnovix
- **Education** — LJMU · IIIT-B · Chandigarh University
- **Contact** — Footer with all social links

---

## Run Locally

**Prerequisites:** Node.js 18+

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build & Export

```bash
npm run build   # Produces static output in /dist
```
